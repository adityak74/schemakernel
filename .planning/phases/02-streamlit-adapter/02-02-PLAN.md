  <files>schemakernel/adapters/streamlit.py</files>
  <action>
    - Define `StreamlitFormAdapter` class.
    - Implement a `_render_field` helper that maps `FieldDefinition` to Streamlit widgets (st.text_input, st.number_input, etc.) per RESEARCH.md.
    - Ensure widget `key` uses the canonical `field.key` for stability.
    - Implement `render_step(self, fields: list[FieldDefinition], current_answers: dict[str, Any], form_key: str = "sk_form") -> dict[str, Any] | None`.
    - `render_step` should:
        1. Open an `st.form(form_key)`.
        2. Iterate over `fields` and call `_render_field` for each, passing current value if present.
        3. Add an `st.form_submit_button`.
        4. If submitted, collect all values from session state or widget returns and return the dict of answers.
        5. Return `None` if not submitted.
